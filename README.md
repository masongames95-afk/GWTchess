# ♟️ Браузерные шахматы (FIDE + База данных JSON + Авторизация)

Интерактивные шахматы в браузере с полноценным движком по правилам FIDE, высокодетализированными PNG-фигурами, звуковыми эффектами, авторизацией пользователей, сохранением в базу данных JSON и онлайн-проверкой существования аккаунтов.

---

## 🚀 Быстрый запуск игры

Для работы авторизации, проверки пользователей и сохранения в базу данных запустите встроенный сервер:

```bash
# Запуск сервера (работает без установки дополнительных пакетов, нужен только Node.js)
npm start
# либо:
node server.js
```

После этого откройте в браузере:
👉 **[http://localhost:3000](http://localhost:3000)**

Для прогона автоматических тестов (движок, база данных, проверка логинов, регистрация, вход):
```bash
npm test
```

## 🔐 Авторизация и База Данных JSON

- **Файл базы данных**: `data/users_db.json`
- **Проверка существования логина**:
  - На форме регистрации при вводе имени поле в реальном времени проверяет через API (`/api/auth/check-username`), существует ли уже такой аккаунт, и показывает статус:
    - 🟢 `✓ Имя пользователя свободно`
    - 🔴 `✗ Аккаунт с таким именем уже существует`
- **Вход в аккаунт**:
  - При попытке входа сайт проверяет наличие аккаунта:
    - Если аккаунт не найден — выдает точное сообщение: *«Пользователь с таким именем не найден в базе данных»* с предложением зарегистрироваться.
    - Если пароль неверный — сообщает: *«Неверный пароль»*.
- **Безопасность**:
  - Пароли **не сохраняются в открытом виде** — используется криптографическое хеширование `crypto.scryptSync` с индивидуальной 16-байтной солью (`salt`) для каждого пользователя.
  - Сравнение хешей защищено от атак по времени через `crypto.timingSafeEqual`.
  - Сессии выдаются через защищенные `HttpOnly` куки `session_id`.
- **Привязка к профилю**:
  - В шапке отображается текущий игрок и его статистика: победы, поражения, ничьи.
  - При завершении партии (мат или пат) статистика в базе данных автоматически обновляется.
  - Кнопка **«💾 Сохранить»** позволяет сохранить текущую партию в базу данных к своему профилю и восстанавливать ее на любом устройстве.

## 🛠️ Возможности шахматного движка

- **Полноценный шахматный движок (Правила FIDE)**:
  - **Шах и Мат**: строгая проверка безопасности короля (связанные фигуры не могут ходить, открывая короля).
  - **Пат (Ничья)**: автоопределение отсутствия легальных ходов при отсутствии шаха.
  - **Рокировка**: короткая ($O-O$) и длинная ($O-O-O$) с проверкой битых полей и промежуточных клеток.
  - **Взятие на проходе (En Passant)**: поддержка взятия на следующем же ходу после двойного шага пешки.
  - **Превращение пешки**: диалоговое окно выбора фигуры (Ферзь, Ладья, Слон, Конь).
  - **Нотация SAN**: генерация стандартной шахматной нотации (включая знаки шаха `+` и мата `#`).
- **Современный дизайн & открытые PNG фигуры**:
  - Высокодетализированные 256x256 PNG-изображения фигур (классический набор Colin M.L. Burnett).
  - Текстурная турнирная доска с ненавязчивой разметкой полей (a–h, 1–8) в углах клеток.
  - Индикация выбранной клетки, точек возможных ходов и контура взятия.
  - Подсветка последнего хода и мерцающий красный индикатор короля при шахе/мате.
  - Кнопка **«Перевернуть доску»** (вид за белых или черных).
  - Подсчет материального преимущества (например, `+3`).
  - Звуковые эффекты на базе встроенного Web Audio API (ход, взятие, шах, победа) с возможностью отключения (кнопка 🔊/🔇).
- **Экспорт и импорт в JSON**:
  - Возможность экспортировать любую партию в отдельный `.json` файл и загружать обратно.

## 📂 Структура проекта

```text
chess/
├── CONTEXT.md               # Архитектурный журнал проекта
├── README.md                # Документация и инструкция по запуску
├── package.json             # NPM-скрипты (npm start, npm test)
├── server.js                # Сервер Node.js (REST API, раздача статики, zero-dependency)
├── index.html               # Главная страница и модальное окно авторизации
├── data/
│   └── users_db.json        # База данных пользователей, паролей, сессий и сохранений
├── src/
│   └── db.js                # Модуль работы с JSON БД, хеширование scrypt и сессии
├── assets/
│   └── pieces/              # PNG фигуры (256x256, Wikimedia Commons)
├── css/
│   └── style.css            # Стили доски, фигур, модальных окон и авторизации
├── js/
│   ├── engine.js            # Ядро шахматных правил (FIDE)
│   ├── auth.js              # Контроллер авторизации, проверка логинов, сессии
│   └── app.js               # Контроллер интерфейса доски, аудио и событий
└── test/
    ├── db_test.js           # Тесты базы данных и хеширования
    ├── server_test.js       # Интеграционные тесты HTTP API сервера
    ├── chess_test.js        # Тесты движка (детский мат, связка, рокировка, en passant)
    └── more_tests.js        # Расширенные тесты (дурацкий мат, двойной шах, превращения)
```
